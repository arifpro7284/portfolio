# Portfolio Project Demos

These four static demo sites correspond to the project cards in the main portfolio. Each folder has its own `index.html`, `style.css`, and `script.js` and can be opened directly in a browser.

## Demos

- `business-website/` - General business site concept with editable placeholder content.
- `restaurant-website/` - Restaurant concept with sample menu filters. It has no real venue details, prices, hours, or reservation endpoint.
- `ecommerce-website/` - Static storefront concept with sample products and a browser-only cart. It does not accept payments or create orders.
- `news-blog-website/` - Editorial concept with original sample copy, working search and filters, and an article dialog. It is not a real publisher or news service.

The personal portfolio is the repository root; a separate duplicate is not included.

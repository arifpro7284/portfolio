GENERAL RULES FOR EVERY PROJECT

- Build a complete, responsive website that works on mobile, tablet, and desktop.
- Use semantic HTML, accessible labels, keyboard-friendly controls, and useful image alt text.
- Keep the code organized and explain how to run the project locally.
- Do not invent real clients, testimonials, company details, contact information, project history, or live URLs. Use clearly labeled editable placeholders where information is missing.

- Before publishing, test all buttons, forms, links, and layouts.
- Add a Live Demo link to the main portfolio only after the website is publicly deployed and its URL has been checked.
